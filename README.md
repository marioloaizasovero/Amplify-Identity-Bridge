# Amplify Identity Bridge

Scaffold inicial para el Toyota VTEX Identity Bridge usando la estructura del template
`marioloaizasovero/amplify-next-template`.

## Estructura

- `app/`: Next.js App Router.
- `app/api/auth/vtex/`: endpoints dummy del bridge.
- `amplify/`: placeholder de backend Amplify Gen 2.
- `lib/`: helpers dummy reutilizables.
- `types/`: tipos compartidos iniciales.
- `public/`: assets estaticos.

## Rutas

- `/`: Hola mundo.
- `/vtex`: pagina dummy del bridge.
- `/api/auth/vtex/authorize`: respuesta dummy.
- `/api/auth/vtex/token`: respuesta dummy.
- `/api/auth/vtex/userinfo`: respuesta dummy.

## Comandos

```bash
npm install
npm run dev
```
